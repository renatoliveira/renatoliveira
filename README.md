# Hi there 👋, I'm Renato

Salesforce Engineer/Developer/Administrator/Architect/AI Whisperer, 15x certified.

Proudly the first person to (publicly on GitHub) publish [a time-based one-time password algorithm in Apex](https://github.com/renatoliveira/time-based-one-time-password-algorithm-in-apex/).

I also write other useful things such as [Apex JSON Path](https://github.com/Dogeforce/apex-json-path), a minimum implementation of JSON Path, but in Apex, the [tile wall](https://github.com/Dogeforce/tilewall-lwc) component that you can show in your Lightning Experience record pages and the [Apex Test List](https://github.com/renatoliveira/apex-test-list) CLI tool, that can come in handy in your CI/CD pipelines for Salesforce projects. Other than those, I like writing software that helps me and others accomplish our jobs with Salesforce.

Some other projects I built include a handful of LWC packages that can be enabled in a project using NPM:

- [Unit Converter LWC @ `@wisefoxme/unit-converter-lwc`](https://www.npmjs.com/package/@wisefoxme/unit-converter-lwc)

Really enjoy contributing to open source projects, being one of the latest the [Apex Test Director](https://github.com/dvnube/apex-test-director), which helped set up tests for a project for a client I worked for [DVNube](https://github.com/dvnube).
